MERCYMED — ВЕСЬ КОД САЙТА
=========================

Это полный исходный код сайта, который вы видите в предпросмотре.
Внутри: 88 файлов. Никаких лишних папок (библиотек, кэша, сборки) — только то,
что нужно для запуска и правки сайта.

ВАЖНО ПРО «HTML И CSS»
----------------------
Сайт сделан не на «голых» HTML+CSS, а на React (фреймворк TanStack Start).
Поэтому:
  - разметка (то, что обычно называют HTML) лежит в файлах .tsx;
  - оформление (CSS) — в одном файле: src/styles.css;
  - чтобы запустить сайт локально, нужны Node.js и npm (команды ниже).

Если вам нужны именно статические .html-файлы (например, чтобы залить на
обычный хостинг без сборки) — скажите, я сделаю отдельную версию сайта
в виде готовых HTML-страниц.

КАК ЗАПУСТИТЬ
-------------
1. Установите Node.js (https://nodejs.org).
2. В папке с сайтом выполните:
     npm install
     npm run dev
3. Откройте адрес, который покажет терминал (обычно http://localhost:8080).

Проверка и сборка:
     npm run build      — собрать сайт для публикации
     npm run lint       — проверка кода
     npm run test       — тесты

ГДЕ ЧТО МЕНЯТЬ (самое частое)
-----------------------------
Телефон, WhatsApp, e-mail, адрес, часы работы, Instagram:
     src/components/site.tsx   — блок CLINIC в самом начале файла
     (сейчас там заглушка: +996 000 000 000 — замените на настоящие)

Цвета бренда, шрифты, скругления, тени:
     src/styles.css   — блок :root (переменные --brand-red, --brand-orange,
                        --brand-yellow, --primary и т.д.)

Тексты главной страницы:
     src/routes/index.tsx

Список услуг и цены:
     src/routes/services.tsx   — массив SERVICES в начале файла
     (цены сейчас «from — som», подставьте свои)

Команда (имена, роли, фото):
     src/routes/team.tsx       — массив TEAM; поле photo — ссылка на фото

Тексты остальных страниц:
     src/routes/about.tsx        — о клинике, миссия, история, ценности
     src/routes/corporate.tsx    — для организаций и посольств
     src/routes/education.tsx    — медицинское образование, ординаторы
     src/routes/outreach.tsx     — мобильные клиники, благотворительность
     src/routes/contact.tsx      — форма записи + контакты + карта

КАК УСТРОЕН САЙТ
----------------
src/routes/        — страницы. Имя файла = адрес страницы:
                     index.tsx → /, about.tsx → /about, services.tsx → /services,
                     corporate.tsx → /corporate, education.tsx → /education,
                     team.tsx → /team, outreach.tsx → /outreach,
                     contact.tsx → /contact
src/routes/__root.tsx — общая оболочка: <head>, шрифты Google Fonts
                     (Manrope и Sora), меню сверху, подвал, страницы 404 и ошибки
src/components/site.tsx — меню, логотип, кнопки «Записаться», карточки,
                     подвал, блок контактов CLINIC
src/components/ui/ — готовые элементы интерфейса (кнопки, поля, диалоги)
src/assets/        — картинки: эмблема, фото клиники и мобильной клиники
src/lib/           — служебные функции
public/            — иконка сайта favicon.ico и robots.txt
package.json       — список библиотек и команды запуска
vite.config.ts, tsconfig.json, eslint.config.js, vitest.config.ts — настройки сборки

ФОРМА ЗАПИСИ
------------
Форма на странице /contact собирает имя, телефон, услугу, дату, язык и
сообщение и открывает WhatsApp с готовым текстом. Ничего не хранится в базе.
Если нужна настоящая запись с сохранением заявок (и страницей, где вы их
видите) — это добавляется отдельным шагом.

ЧТО ПОКА НЕ СДЕЛАНО
-------------------
- Кыргызский и русский языки интерфейса (сейчас сайт только на английском).
- Настоящий номер телефона, адрес, e-mail и Instagram (везде заглушки).
- Реальные фото клиники (две картинки сгенерированы как временные).
- Админка, чтобы менять тексты и цены самому.
- Настоящая онлайн-запись с сохранением заявок.
